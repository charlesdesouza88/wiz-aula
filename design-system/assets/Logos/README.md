# Logos

- `mister-wiz-logo.png` — the MISTER WIZ wordmark, `logo-ink` (#241F21) letters with the figure's head in `logo-purple` (#713C97), transparent background, 477 × 63. Use on light grounds (`bg`, `surface`).
- `mister-wiz-logo-white.png` — the same wordmark in white with the head in light purple (#C47FCF), for the dark theme. Made from the original by recoloring only.
- `mister-wiz-symbol.png` — the Mister Wiz symbol: white figure on the vertical gradient `symbol-top` (#72227B) → `symbol-bottom` (#351B48), 512px, square. The app icon; also the `BrandMark` tile.
- `mister-wiz-symbol-maskable.png` — the symbol with the figure at 78% inside the safe zone, for Android adaptive icons.
- `mister-wiz-symbol-white.png` — the figure alone, white on transparent, for placing on purple or photos.
- `notification-badge-96.png` — the figure alone, white on transparent, for the Android status-bar badge.

The symbol files were redrawn at icon sizes from a 225px source by tracing the figure and rebuilding the gradient from sampled colors; ask for the original vector before printing large.

Earlier Wiz Aula camera-mark files (`wiz-aula-mark.svg`, the old app icons) are retired; the Mister Wiz files above replace them.
