# LiveDot
`.live-dot` is the 12px red dot that pulses while a class is live.

- **Source:** `src/app/globals.css` (`.live-dot`, `@keyframes live-pulse`).
- Size `live-dot`, `live` fill, a 1.6s ring pulse; still under `prefers-reduced-motion`.
- Always `aria-hidden` and always followed by words in `live-ink` ("Aula ao vivo agora").
